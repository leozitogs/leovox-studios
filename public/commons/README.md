# commons

Assets genéricos que não pertencem a uma cena específica (ícones,
elementos repetidos, decorações).

- `pixacao-half-style.svg`, `seta-half-style.svg`,
  `star-half-style-1-green.svg` e `star-half-style-2-white.svg`:
  grafismos half-style da identidade (assinatura própria, não spray
  genérico, liberados pela regra de marca). Estreiam no cartaz de
  abertura da cena Pilares e podem se repetir em outras cenas.
