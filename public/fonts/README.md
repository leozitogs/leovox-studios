# Fontes da marca

Dropar aqui os arquivos .woff2 com exatamente estes nomes
(referenciados no @font-face de `src/styles/tokens.css`):

| Arquivo esperado            | Fonte                  | Papel                                 |
| --------------------------- | ---------------------- | ------------------------------------- |
| `Anton-Regular.woff2`       | Anton                  | Display primária, headlines           |
| `BebasNeue-Regular.woff2`   | Bebas Neue             | Numeração, métricas, kickers, labels  |
| `Extenda-30.woff2`          | Extenda 30             | Momentos-assinatura (corte licenciado) |
| `Extenda-40.woff2`          | Extenda 40             | Momentos-assinatura (corte licenciado) |
| `Extenda-60.woff2`          | Extenda 60             | Momentos-assinatura (corte licenciado) |
| `Montserrat-Variable.woff2` | Montserrat (variável)  | Corpo institucional                   |
| `Poppins-Regular.woff2`     | Poppins 400            | Corpo conversacional, formulário      |
| `Poppins-Medium.woff2`      | Poppins 500            | Microcopy com ênfase                  |
| `LostInSouth-Regular.woff2` | Lost in South          | Selo Isso é Leovox                    |
| `Schoolbell-Regular.woff2`  | Schoolbell             | Anotação à mão                        |

Se algum arquivo vier com outro nome ou formato (ttf/otf),
avisar para ajustarmos o tokens.css ou converter para woff2.
