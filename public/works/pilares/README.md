## Regras

- Não incluir dado privado, credencial ou identificação de usuário.
- Confirmar autorização pública do cliente antes de preencher `src`.
- SVG é preferido para marcas e símbolos.
- Imagens raster devem preservar margem para crops responsivos.
- Vídeos entram mudos, em loop, com poster e `preload="metadata"`.
